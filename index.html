Language reference
Use integers and variables, assignments, print(value);, if (...) { ... } else { ... } and while (...) { ... }. End assignments and print with a semicolon.
let x = 3; declares a variable. x = 4; changes it. A first assignment without let also creates a variable. Variables are global. A variable must have a value on the path being executed before it can be read.
Operators: + − * / %, < <= > >= == !=, && || !. Logical operators short-circuit. Zero is false; other integers are true. Comments use // or /* ... */.
Signed 32-bit integers wrap on overflow. Division truncates toward zero. Decimal literals only; no strings, functions, arrays, input, floating point or ++.

What is happening at each stage?
Lexer: recognises words, numbers and punctuation. Parser: groups those tokens into a syntax tree using precedence rules. Compiler: emits stack instructions and patches jump addresses. Machine: executes those instructions using its program counter, operand stack and variable memory.
Constant folding computes pure constant expressions during compilation. The syntax tree stays unchanged so you can compare the original expression with the reduced instruction list. It does not remove variable reads or skip runtime errors.
The ACC display holds the most recently loaded or calculated value. The stack stores operands; RAM stores variables. PC is the address of the next instruction. The step counter counts instructions, not hardware clock cycles.
